# 严正声明

近日，Team Sirius开发团队发现有人在未标注出处的情况下，分发团队开发的WDS Editor程序安装包，并使用其制作并公开发布内容，为自己的服务器吸引热度。这违反了项目所遵循的开源协议，且分发者不提供出处与源码的分发方式也严重违背了自由软件与开源精神。

Team Sirius开发团队选择开源本项目的初衷，是为了方便各位使用者根据自己的需求修改项目、定制功能，也是为了给希望开发类似功能项目的开发者提供参考，而不是让本项目成为他人为自己吸引热度的工具。鉴于这些行为已经严重触碰了Team Sirius开发团队的底线，现作出如下决定：从本声明正式发布起，完全停止本项目的开源版本的维护工作，项目将以闭源形式继续开发，且不再公开提供项目安装包。

感谢您的理解与支持。带来不便，敬请谅解。
